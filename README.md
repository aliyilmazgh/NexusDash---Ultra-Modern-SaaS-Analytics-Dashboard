**NexusDash** is a high-performance, visually stunning SaaS Management Dashboard designed to showcase modern UI/UX principles integrated with a scalable backend architecture. Built for speed, aesthetics, and data clarity.

---

## ✨ Key Features

- 📊 **Real-time Data Visualization:** Interactive revenue forecasting using Chart.js.
- 💎 **Modern Glassmorphism UI:** Deep-dark theme with Tailwind CSS, utilizing backdrop-blurs and custom gradients.
- 📱 **Fully Responsive:** Seamless experience across Mobile, Tablet, and Desktop.
- ⚡ **Lightweight Architecture:** Zero-framework frontend (Vanilla JS) for maximum performance.
- 🛠️ **Professional API Mocking:** Robust Node.js/Express backend ready for production scaling.

---

## 🛠️ Tech Stack

### Frontend
- **HTML5/CSS3** (Custom Animations)
- **Tailwind CSS** (Utility-first styling)
- **Lucide Icons** (Minimalist iconography)
- **Chart.js** (Dynamic data rendering)

### Backend
- **Node.js** (Runtime environment)
- **Express.js** (RESTful API design)
- **Architecture:** Controller-based logic separation (Mocked)
